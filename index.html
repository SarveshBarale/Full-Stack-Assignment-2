1. Introduction

HTML stands for HyperText Markup Language. It is used to create the structure of a web page. HTML5 is the latest version of HTML.

In the older HTML (HTML 4.01 and before) we had to use plugins like Flash for video and many <div> tags for the layout. HTML5 added new tags, new form inputs, audio and video support, canvas and many APIs, so these things can now be done without extra plugins.

2. Difference between HTML and HTML5

Point HTML (older versions) HTML5
Doctype Very long and difficult to remember Short: <!DOCTYPE html>
Character set Long meta tag with http-equiv <meta charset="UTF-8">
Page structure Only <div> tags with ids Semantic tags like header, nav, main, section, article, aside, footer
Audio and video Needed plugins like Flash Built-in <audio> and <video> tags
Graphics Only images or plugins <canvas> and <svg>
Forms Only text, password, checkbox, radio. Validation needed JavaScript New types like email, date, number, range, color. Also required and placeholder
Storage Only cookies (about 4 KB) localStorage and sessionStorage (about 5 MB)
APIs Very few Geolocation, Drag and Drop, Web Workers
Old tags font, center, big, strike were used These tags are removed. CSS is used instead
SEO and accessibility Less meaning in the tags Semantic tags help search engines and screen readers
Mobile support Not made for mobile Made with mobile devices in mind

3. Main Features of HTML5

Semantic tags

These tags tell us what the content is.

<header></header>
<nav></nav>
<main>
  <article></article>
  <aside></aside>
</main>
<footer></footer>

Audio and Video

We can play media without any plugin.

<video controls width="300">
  <source src="movie.mp4" type="video/mp4">
</video>

Canvas

Used to draw shapes using JavaScript.

<canvas id="myCanvas" width="200" height="100"></canvas>

New form inputs

The browser checks the values by itself.

<input type="email" required>
<input type="date">
<input type="range" min="0" max="10">

Web storage

Data can be saved in the browser.

localStorage.setItem("name", "Sarvesh");
localStorage.getItem("name");

4. Good HTML vs Bad HTML

Below is the same small blog page written in a bad way and in a good way.

Bad HTML (non-semantic, poor structure)

<html>
<body>
<center>
  <font size="6" color="blue">My Blog</font>
</center>
<div class="top">
  <div><a href="/">Home</a></div>
  <div><a href="/about">About</a></div>
</div>
<div class="post">
  <div class="big">Why I like HTML5</div>
  <img src="pic.jpg">
  It is simple. <br><br>
  It is powerful.
</div>
<div class="bottom">
  <b><i>Copyright 2026</i></b>
</div>
</body>
</html>

What is wrong:

  • No doctype, no head, no title and no lang attribute.
  • Uses the old tags center and font.
  • Everything is a div, so the browser does not know which part is the menu or the main content.
  • The heading is a div, not an h1 or h2.
  • The menu is not a list. br is used instead of paragraphs.
  • The image has no alt text.

Good HTML (semantic, proper structure)

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Blog</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <h1>My Blog</h1>
    <nav>
      <ul>
        <li><a href="/">Home</a></li>
        <li><a href="/about">About</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <article>
      <h2>Why I like HTML5</h2>
      <img src="pic.jpg" alt="Laptop with code">
      <p>It is simple.</p>
      <p>It is powerful.</p>
    </article>
  </main>
  <footer>
    <p>&copy; 2026 My Blog</p>
  </footer>
</body>
</html>

What is good:

  • Has the doctype, lang, charset and title.
  • Uses header, nav, main, article and footer for the correct parts.
  • Proper headings, a list for the menu and real paragraphs.
  • The image has alt text.
  • The styling is in a separate CSS file.

Why good HTML is better

  • It is easier to read and maintain.
  • It is better for search engines (SEO).
  • Screen readers can understand the page, so it is more accessible.
  • It works the same in all browsers.

6. Conclusion

HTML5 is the improved version of HTML. It gives us semantic tags, audio and video, canvas, better forms and web storage. Because of this, web pages are easier to build, easier to maintain and better for SEO and accessibility.

Good HTML uses the correct semantic tags and keeps the design in CSS. Bad HTML uses too many divs, old tags and misses basic things like alt text and headings.
