# HTML vs HTML5

A web page made for the Full Stack Development course. It explains the differences between HTML and HTML5 and shows examples of good (semantic) and bad (non-semantic) HTML.

**Live demo:** https://your-username.github.io/your-repo-name/

## What the page covers

- Introduction to HTML and HTML5
- Comparison table (doctype, structure, forms, media, storage, APIs and more)
- Main HTML5 features with code snippets
- Good HTML vs bad HTML with the same page written both ways
- Working demos: semantic layout, HTML5 form validation, canvas, local storage and the audio tag

## Technologies used

- HTML5
- CSS3
- JavaScript

## Project structure

```
html5-assignment/
├── index.html   # page content
├── style.css    # styling
├── script.js    # form, canvas and local storage demos
└── README.md
```

## How to run

1. Download or clone this repository.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open `index.html` in any web browser.
